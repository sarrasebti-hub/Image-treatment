# Search index

- `kb_manifest.json`: index type, similarity, sizes, indexing time and checks
- `caption_to_image.json`: link from each caption vector to its photo
- `kb_records.json`: for each library photo: raw and cleaned captions, caption ids, file name and YOLO object labels

The FAISS files (`kb_image.index`, `kb_caption.index`) are on the team's Google Drive.
