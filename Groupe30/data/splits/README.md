# Frozen splits

- `kb_ids.json`: 10,000 library photos (COCO train2017)
- `val_ids.json`: 100 validation photos (COCO train2017, different from the library)
- `test_ids.json`: 1,000 test photos (COCO val2017)
- `test_ids_100.json`: 100 test photos selected from the 1,000 (30 simple, 40 medium, 30 complex scenes), kept for comparison
- `cleaning_report.json`: missing, corrupted and duplicate photo check, and caption counts

All lists were drawn with seed 42. Do not edit these files.
