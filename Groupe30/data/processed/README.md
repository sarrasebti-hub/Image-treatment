# Processed data

- `kb_captions.jsonl`: one line per library caption (`caption_raw` and `caption_clean`)
- `caption_audit.json`: caption counts and the leakage audit
- `eval_references_val.json`, `eval_references_test.json`: raw human captions of the validation and test photos
- `yolo_metadata.json`: objects detected in the library and validation photos
- `yolo_metadata_test.json`: objects detected in the test photos
- `yolo_settings.json`: detector model, version and settings
