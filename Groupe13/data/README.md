\# Data Directory



This directory contains the datasets and generated files used in the COCO Image Captioning RAG project.



\## Structure



\- `annotations/`: COCO annotation files.

\- `train2017/`: Training images.

\- `val2017/`: Validation and test images.

\- `splits/`: Knowledge Base, validation, and test image IDs.

\- `captions/`: Raw and cleaned captions.

\- `metadata/`: Extracted object and spatial metadata.

\- `processed\_images/`: Preprocessed images.

\- `embeddings/`: CLIP image and text embeddings.

\- `index/`: FAISS vector indexes.



\*\*Note:\*\* Dataset files and generated artifacts are not included in this GitHub repository because of their large size.
